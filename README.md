# P2P File Transfer

A learning project: a small Python app that lets two people send files
directly to each other over the internet.

See [docs/DESIGN.md](docs/DESIGN.md) for the full design and the
phase-by-phase build plan.

## Status
🚧 In development — building phase by phase. See commit history for
progress log.

## Requirements (planned)
- Python 3.10+
- `cryptography` library (for encryption)
